LC 1046 — Last Stone Weight

Algorithm

    

      
1. Build max-heap from stones.

      
2. While size > 1:

      

        
y = heap.poll()

        
x = heap.poll()

        
if y != x:

        
heap.offer(y − x)

      

      
3. Return 0 if empty, else peek().

    


    

      
Why a max-heap?

      

        Each round needs the two heaviest stones. A max-heap gives both in O(log n) each via poll(). Sorting and re-sorting every round is O(n² log n); the heap brings the total to O(n log n).
      

    


    

      
Why y − x ≥ 0?

      

        A max-heap pops in non-increasing order, so the first poll y is always ≥ the second poll x. Pushing y − x is a valid non-negative stone weight — no abs-value needed.

Complexity

      

        Time: O(n log n) — up to n iterations, each with two polls + one offer at O(log n). 

        Space: O(n) for the heap.

        Build loop is O(n log n); drop to O(n) with constructor heapify.
