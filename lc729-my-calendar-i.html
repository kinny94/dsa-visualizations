LC 729 — My Calendar I

Algorithm

    

      
book(s, e):

      

        
• prev = floorKey(s)

        
• next = ceilingKey(s)

        
• leftOK  = prev==null ||

        
   map.get(prev) ≤ s

        
• rightOK = next==null ||

        
   e ≤ next

        
• if both → put, return true

        
• else return false

      

    

    

      
Why only two neighbors?

      

        Stored intervals are non-overlapping by construction — we rejected every would-be overlap. So they lie strictly sorted-and-separated on the timeline. If the new interval overlaps anything, it must overlap the closest one on each side; it can't reach further without first swallowing the nearer one.
      

    

    

      
Half-open semantics

      

        Intervals are [start, end). Touching endpoints are allowed: [10, 20) and [20, 30) don't overlap. That's why checks use ≤, not <.
