Three cases (same as LC 938)

    

      
val < low

      
Drop node AND left subtree. Return trim(node.right) — right side might still have survivors.

      
val > high

      
Drop node AND right subtree. Return trim(node.left).

      
low ≤ val ≤ high

      
Keep node. Rewire: node.left = trim(node.left), node.right = trim(node.right). Return node.

    

    

      
The rewire trick

      

        root.left = trim(root.left) is the magic line. If trim returns a different node (because the original child was dropped but a grandchild survived), the parent's child slot captures that new attachment. One assignment handles keep, drop, and re-parent uniformly.
