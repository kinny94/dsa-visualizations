Algorithm

    

      
Inorder with two fields:

      

        
• solve(node.left)

        
• if last != null:

        

          
- last.right = node

          
- node.left  = last

        

        
  else first = node

        
• last = node

        
• solve(node.right)

      

      
After traversal: close the circle
last.right = first; first.left = last.

    

    

      
Why inorder?

      

        A BST's inorder traversal yields its values in sorted order. The problem wants a sorted DLL, so each inorder visit is handed the correct next neighbor for free — nothing to compare or sort.
      

    

    

      
The two instance fields

      

        last is the previously visited node — the bridge for wiring. first is locked on visit #1 — we need it later to close the circle. Both are instance fields so recursion frames share them.
