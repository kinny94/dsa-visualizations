return vs global

      Return value = one-sided gain the PARENT can extend (a path can't fork through a node).
      Global max = path that bends AT this node (uses BOTH sides). We never return the bend, only record it.
    

    

      
why clamp to 0

      If a subtree's return gain is negative, don't take it. Starting fresh (gain = 0) is always at least as good. That's the Math.max(0, childReturn) clamp.
