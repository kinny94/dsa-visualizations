Algorithm

    

      
• If node == null → return new TreeNode(val).

      
• If val < node.val → node.left = insert(node.left)

      
• Else → node.right = insert(node.right)

      
• Return node.

    

    

      
Why no rotations

      

        LC 701 accepts any valid BST, not a balanced one. Rotations (AVL / Red-Black) are needed only when the problem requires an O(log n) height guarantee after many inserts. Here, plain descent is correct.
      

    

    

      
The rewire idiom

      

        node.left = insert(node.left) handles the leaf case uniformly: when insert returns a freshly-created node, the parent's child slot captures the attachment. No separate "plant it" step needed. Same magic as LC 669 trim.
