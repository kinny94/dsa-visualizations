LC 1008 — Construct BST from Preorder Traversal

Walk preorder with a monotonic-decreasing stack of the "rightmost spine". Each value either slots as left-child of top (if smaller) or pops until it finds its right-parent (if larger). O(n) amortized. preorder = [8, 5, 1, 7, 10, 12].

Algorithm

    
root = new Node(preorder[0]);
stack.push(root);
for (i = 1; i < n; i++) {
  v = preorder[i];
  node = new Node(v);
  if (v < stack.top().val) {
    stack.top().left = node;
  } else {
    parent = null;
    while (!stack.empty()
           && stack.top().val < v) {
      parent = stack.pop();
    }
    parent.right = node;
  }
  stack.push(node);
}

    

      
Stack invariant

      

        The stack holds the rightmost spine of the tree being built — nodes whose right child slot is still open, strictly decreasing from bottom to top.
      

    

    

      
Why last-popped is the parent

      

        When we pop while top < v, each popped node's subtree is done — v doesn't fit as their left child (too big) nor as their right child (there's a smaller eligible ancestor). The last pop is the shallowest ancestor whose right subtree v starts.
      

    

    

      
Why O(n)?

      

        Each node is pushed and popped at most once — amortized O(1) per preorder element. Total O(n) time, O(h) space.
