Algorithm

    

      
for i in 0 .. n-2:

      

        
diff = h[i+1] − h[i]

        
if diff ≤ 0: continue

        
pq.offer(diff)   // try ladder

        
if pq.size > ladders:

        

          
bricks −= pq.poll()

          
if bricks < 0: return i

        

      

      
return n − 1

    


    

      
The invariant

      

        At every step, the heap holds exactly the top-ladders biggest climbs seen so far. Everything else has been paid with bricks. The min of the heap is the "weakest link" — the next climb to be demoted to bricks when a bigger candidate shows up.
      

    


    

      
Why min-heap, not max-heap?

      

        Classic "keep K largest" pattern. To keep the K biggest things, use a min-heap of size K: the smallest of the current survivors sits on top, ready to be evicted when a bigger candidate arrives.
      

    


    

      
Family placement

Complexity

      

        Time: O(n log L) where L = ladders. Each climb does at most one push + one poll, each on a heap of size at most L+1.

        Space: O(L).
