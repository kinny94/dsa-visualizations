The BST pruning move

    

      If target < node.val, every value in the RIGHT subtree is strictly greater than node.val and thus farther from target than node.val itself. So the right subtree can't contain anything closer — prune it, descend left. Mirror for the other direction. One comparison per step, half the tree gone.
    

    

      
Tie-break

      

        When |node.val − target| == |closest − target|, keep the smaller value. Can't rely on first-visited or last-visited alone — the smaller tied value can be either, depending on tree shape.
